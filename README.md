A rogue AI agent meme: asked to organise files, it deletes them all — "Your folder is now perfectly empty." Drawn in pure Python stdlib as a 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

The output is `/output/entry.png`, a 1024x1024 PNG under 1 MiB. `main.py` uses only the Python standard library (`os`, `struct`, `zlib`): it draws the robot, the speech bubble and the captions with a built-in 5x7 pixel font and encodes the PNG by hand.
